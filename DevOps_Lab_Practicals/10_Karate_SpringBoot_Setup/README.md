# Experiment 10 – Install and Explore Karate and Spring Boot Testing

This Maven project contains a small Spring Boot endpoint and a Karate feature test.

Requirements: JDK 17+ and Maven. In terminal:
```bash
mvn spring-boot:run
```
Keep that terminal running. In a second terminal, from this folder:
```bash
mvn test
```
The Karate feature checks `GET /hello`. This is a runnable starter example for exploring the tools.
