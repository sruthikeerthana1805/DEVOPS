# DevOps Lab Practicals – Cycle 1 and Cycle 2

This repository contains practical starter code and command notes organized into 12 experiments.

## Experiments
1. Event Registration using Express
2. Git and GitHub Commands
3. Source Code Management on GitHub
4. Jenkins Installation and Setup
5. CI/CD Pipeline using Jenkins
6. Docker Commands
7. Containerized Flask Application using Docker
8. Integrate Kubernetes and Docker
9. Automate Containerized Applications using Kubernetes
10. Karate and Spring Boot Testing Setup
11. JavaScript Program and Karate Testing
12. Spring Boot Test Cases

## Notes about the supplied lab records
Experiments 1–9 are organized from the uploaded lab-record material. The uploaded PDFs did not include the detailed program pages for Cycle 2 experiments 3–5 (overall experiments 10–12); those folders therefore contain clearly identified starter examples based on the syllabus aims, not transcriptions of the missing record pages.

See each experiment folder's README for commands and execution steps.
